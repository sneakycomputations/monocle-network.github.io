Community Reserves

Monocle allocates 33% of collected network fees to three community reserves:

Peer Security Reserve

Haveno Network Development Grant

Open Source Sustainability Grant

These reserves are designed to protect network peers in the event of exploits and support development of Haveno and other open-source projects useful to Monocle.

For more information read the Reserve Allocation Policy.

Exploit response: peer safety is Monocle's top priority, so in case of security exploits targeting peers' balances, all the XMR in reserves will be directed toward reimbursing affected peers.

Transparency: all reserve addresses will be published together with their view key. Monocle will also publish transaction IDs and transaction keys for any distributions made from these wallets.
