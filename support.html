Contact, support & community

SimpleX

SimpleX is the fastest way to reach Monocle, with contributor responses often within 3 hours vs. 24 hours on other channels.

For the best experience, install the SimpleX desktop client from the official download page.

A custom name and profile picture are strongly encouraged to help contributors distinguish you from other peers.

To join rooms, open this webpage on a desktop, then right-click each link below and select Copy. Paste the link into the SimpleX client's search bar.

  • Support - Live community support
  • Arbitrators - The place to contact arbitrators about open cases
  • Chat - General chat about Monocle and Monero

GitHub

GitHub is Monocle's main hub. It's where announcements are made, discussions happen, decisions are recorded, and ongoing work is tracked. If something matters, you'll likely find it on [https://github.com/monocle-network].

The Community Forum is hosted on GitHub Discussions and available at [https://github.com/orgs/monocle-network/discussions].

Wiki

Monocle Network offers a growing knowledge base with its wiki, available at monocle.wiki.

Matrix and Telegram

Support contributors also monitor Matrix and Telegram, which are maintained as secondary support channels:

  • Matrix - Community support and discussion
  • Telegram - Community support and discussion

Social Networks

Monocle also has the following social media accounts:

  • Monocle subreddit - Community discussion
  • X/Twitter - Announcements
  • Nostr - Announcements
  • YouTube - Explainer videos

Support language

All support is provided in English.

Additional information

For more information, please see the Support Policy and the Community Guidelines.
