# Haveno

Monocle Network is a fork of the open source Haveno project.

For more information on Haveno, see:

* [Haveno website](https://haveno.exchange/)
* [Haveno GitHub](https://github.com/haveno-dex/haveno)

## Monocle Network Is Built on Haveno

Haveno is an actively developed open-source project and a fork of [Bisq](https://bisq.network), a Bitcoin peer-to-peer (P2P) trading platform. The Haveno team develops open-source P2P software for trading Monero, which anyone can use to operate their own network. Monero serves as the base currency for all trades, providing privacy at the protocol level.

The Haveno platform allows peers to buy and sell Monero for fiat, Bitcoin, and other cryptocurrencies. Trades are conducted directly between peers over Tor, including all communication involved in making and taking offers.

Haveno does not operate its own network. Instead, the software is made available for anyone, such as Monocle, to operate an independent network.

## Monocle Will Support Haveno Development

Haveno is a vital open source project for the Monero community. That is why 33% of collected network fees go to [Community Reserves](https://), which include the [Haveno Network Development Grant](https://). This is Monocle's way of giving back to the Haveno project.

## Monocle's Aims

Monocle aims to utilize the Haveno open source project to:

1. Put peers at the forefront of decision making.
2. Maintain low, transparent, and capped network fees. 
3. Provide responsive, multi-channel support that respects peers' time.
4. Provide transparency regarding network fees and reserve wallets through cryptographic proof, including view keys, transaction IDs, transaction keys, and a published ledger of all relevant transactions.
5. Build a positive, active community where peers feel heard and valued.
6. Create compensated contribution opportunities in Monero for community members, node operators, support team members, and more.
7. Be net contributors to the Haveno community, the wider Monero ecosystem, and the open-source ecosystem.
8. Expand Haveno's reach to new peers while providing existing peers with more choice. 
9. Support open-source projects that lack a direct path to revenue but are vital to the ecosystem.
10. Commit to peers through actions, not words.
