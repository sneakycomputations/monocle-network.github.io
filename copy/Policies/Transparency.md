# Transparency

Monocle Network is committed to transparency. 

### Network Fees

The community reserve addresses are shared together with their respective view keys, so anyone can confirm that 33% of the network fees are distributed to these addresses.

### Contributors

Each contributor will post their compensation request for any delivered tasks to a public GitHub repository, along with their receive address. Monocle will publish the transaction ID and key after the compensation has been distributed.

Contributor compensation requests, addresses, transactions IDs and keys are maintained in the [compensation repository](https://) for community audit.
