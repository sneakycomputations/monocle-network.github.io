# Network Fees

**Network fees will be limited to 0.3% for the first 12 months of operations**, in order to incentivize peer activity on the platform.

Allocation will be as follows:

* Maker: 0.1%
* Taker: 0.2%

The network fee applies across all supported assets. Tiered pricing is not employed.

Due to on-chain consolidation costs, the minimum fee is currently set at 0.0025 XMR per peer, and for no-deposit offers the seller-maker covers the fees of both roles, with a minimum fee of 0.005 XMR.

**33% of collected network fees are allocated toward peer security, Haveno development, and open-source project support.**

See [Community Reserves]() for detailed information, wallet addresses, and view keys.

## Network Fee Transparency

After the initial 12-month period, fees may increase over time. See the [Fee Adjustment Policy](https://) for more information. This allows Monocle to invest in operating a high-quality network, attracting talented contributors, and growing peer participation.

Monocle commits to the following:

1. **Transparency**: View keys for the network fee address will be available, and fee collection totals will be published in the GitHub repository.
2. **Long-term cap**: Total fees are not expected to ever exceed 1% of the trade amount, shared between the maker and taker.
5. **Community discussion**: Any proposal to increase fees will be published on GitHub for community discussion.
6. **Advance notice**: Following community discussion, peers will receive 30 days' notice before any fee changes take effect.

The network's growth strategy prioritizes broad accessibility. Network fee levels will remain competitive to support this objective.
