# Contact, support & community

## SimpleX

SimpleX is the fastest way to reach Monocle, with contributor responses often within 3 hours vs. 24 hours on other channels.

For the best experience, install the SimpleX **desktop** client from the [official download page](https://simplex.chat/downloads/#desktop-app).

**A custom name and profile picture are strongly encouraged** to help contributors distinguish you from other peers.

To join rooms, open this webpage on a desktop, then right-click each link below and select Copy. Paste the link into the SimpleX client's search bar.
- [Support](https://smp12.simplex.im/g#4bx6XCFxo1854SgPQ8YVS_iUSQRxwyop0FxzwjyOO-o) - Live community support
- [Arbitrators](https://smp10.simplex.im/g#h3fyE2SBfsoUmriMQYoZ197zcelbMC45YPdYaqHlq9Q) - The place to contact arbitrators about open cases
- [Chat](https://smp11.simplex.im/g#mOn80veJGaMOPgEd1XM4-uXVyMx6QdTziPjcQj_SKLM) - General chat about Monocle and Monero


## GitHub

GitHub is Monocle's main hub. It's where announcements are made, discussions happen, decisions are recorded, and ongoing work is tracked. If something matters, you'll likely find it on [https://github.com/monocle-network].

The Community Forum is hosted on GitHub Discussions and available at [https://github.com/orgs/monocle-network/discussions].
