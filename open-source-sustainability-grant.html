Community Reserves

Open Source Sustainability Grant

Open-source software is foundational to Monocle Network, and donations to OSS projects help maintain a healthy ecosystem.

XMR in the Open Source Sustainability Grant is reserved for open-source donations, or compensating participants affected by an exploit.

All donations are announced publicly, and project teams must confirm their XMR address on a GitHub issue before distribution. The transaction ID and key are then published as a comment, allowing anyone to independently verify that the donation has been distributed to the address provided.

Eligible Open-Source Projects

  • Supporting the network (e.g., Tor)
  • Benefiting Monero in general or Monocle specifically (e.g., UI for Monero multisig wallets)

One annual donation is planned, utilizing all funds accrued in the Open Source Sustainability Grant. This is for a few reasons:

  • Less administration required.
  • Maximizing the impact for the chosen OSS project.
  • During the first year of operation, Monocle Network aims to retain as much of the balance as possible for the Peer Security Reserve.

Selection of Beneficiary Projects

Initially, beneficiaries will be selected by network maintainers among those projects required to operate the network, while future iterations may consider community input.

Donation Process

All distributed donations will be published on this page, with links to the GitHub issues containing donation proofs.
